# Sum of Two Numbers

Read two integers and print their sum.

## Input

Two integers $a$ and $b$ ($-10^9 \leq a, b \leq 10^9$)

## Output

Print a single integer: $a + b$

## Example

**Input:**
```
3 5
```

**Output:**
```
8
```

## Constraints

- Time limit: 1 second
- Memory limit: 256 MB

## Notes

This is a simple problem designed for testing the AI Optimization Arena platform.
The solution should handle edge cases including:
- Large positive numbers
- Large negative numbers
- Zero values
- Mixed positive and negative numbers
